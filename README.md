# 🏥 FISIOTECH+ | Sistema Web para Clínica de Fisioterapia

[![INDAUTOR Registered](https://img.shields.io/badge/Registro-INDAUTOR-blue.svg)](#-propiedad-intelectual-e-investigación)
[![Academia Journals](https://img.shields.io/badge/Congreso-Academia%20Journals-green.svg)](#-propiedad-intelectual-e-investigación)
[![Stripe Integrated](https://img.shields.io/badge/Pagos-Stripe-purple.svg)](#-tecnologías-utilizadas)

**FISIOTECH+** es una plataforma web integral desarrollada colaborativamente para clínicas de fisioterapia. Está diseñada para optimizar la gestión de servicios de rehabilitación, facilitar el agendamiento y ofrecer un procesamiento seguro de pagos en línea para los pacientes.

---

## ✨ Características Principales

* **🖥️ Interfaz Web Responsiva:** Diseño adaptable a dispositivos móviles, tabletas y computadoras de escritorio.
* **💳 Pasarela de Pagos en Línea:** Integración directa con **Stripe API** para cobros rápidos y seguros.
* **📋 Catálogo de Servicios:** Módulo interactivo con información detallada de terapias, consultas y especialidades.
* **🎨 Experiencia de Usuario Intuitiva:** Navegación optimizada para facilitar la interacción de pacientes y personal técnico.

---

## 🔬 Propiedad Intelectual e Investigación

* **📜 Registro ante INDAUTOR:** El desarrollo del código fuente, arquitectura y diseño de la plataforma **FISIOTECH+** cuenta con registro oficial de propiedad intelectual ante el **Instituto Nacional del Derecho de Autor (INDAUTOR)**.
* **📄 Artículo Científico:** Se redactó y presentó un *paper* de investigación sobre el proyecto en el **Congreso Internacional de Investigación Academia Journals Celaya**.

---

## 🛠️ Tecnologías Utilizadas

* **Frontend:** HTML5, CSS3, JavaScript (ES6+)
* **Framework CSS:** Bootstrap
* **Integración de Pagos:** Stripe JavaScript SDK / API
* **Control de Versiones:** Git & GitHub
